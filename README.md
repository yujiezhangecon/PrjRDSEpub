# PrjRDSEpub
RDSE public repository. 

## Folder: data 

This is the folder for data files constructed from raw data. 
For many data files, there are two versions: .csv and .dta as they can be used for both Python and STATA scripts. Regardless of the format, files with the same names are the same datasets.

## Folder: data_raw 

This is the folder for raw data files directly downloaded from resources' websites. 

## Folder: data_to_est 

This is the folder for data files that are used for estimations. 

## Folder: script_Python 

This is the folder for scripts run in Python (.py files).

## Folder: script_Stata

This is the folder for scripts run in Stata (.do files).
